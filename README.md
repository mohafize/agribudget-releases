# أجري بدجت — الإصدار ١٫٠

هذا المستودع مخصص لتنزيل الحزم الثنائية الرسمية لتطبيق أجري بدجت ووثائقها فقط. الشفرة المصدرية للتطبيق خاصة وغير منشورة.

أجري بدجت تطبيق محلي لإدارة الميزانية الزراعية. لا توجد حسابات أو تحليلات أو تتبع أو مزامنة، وتظل بيانات كل جهاز محلية ومستقلة.

# AgriBudget — Version 1.0

This repository is solely for the official binary downloads and public documentation of AgriBudget. The application's source code is private and unpublished.

AgriBudget is a local-first agricultural budget application. There are no accounts, analytics, tracking, or synchronization; each device keeps independent local data.

## Downloads

### Android

- [Direct-download Android package](https://github.com/mohafize/agribudget-releases/releases/download/v1.0.0/AgriBudget-1.0-Android-universal.apk)
- [Complete Android archive with licenses and instructions](https://github.com/mohafize/agribudget-releases/releases/download/v1.0.0/AgriBudget-1.0-Android-complete.zip)

This is a direct download, not an app-store release. It runs on devices using 4 KB memory pages and uses Android's official compatibility mode on 16 KB devices; it is not currently natively 16 KB compatible. See the [English](INSTALL-ANDROID-EN.txt) or [Arabic](INSTALL-ANDROID-AR.txt) installation instructions.

### Windows

- [Portable self-contained Windows build](https://github.com/mohafize/agribudget-releases/releases/download/v1.0.0/AgriBudget-1.0-Windows-x64-portable.zip)

The Windows build is not digitally signed, so Windows may show an unknown-publisher or reputation-protection warning. Verify the download source and checksum before proceeding. See the [English](RUN-WINDOWS-EN.txt) or [Arabic](RUN-WINDOWS-AR.txt) instructions.
